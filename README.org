* Dotfiles

This repository contains all my public configuration files. I manage
the dotfiles with [[https://www.gnu.org/software/stow/][GNU Stow]].

My computers run Debian with Guix. Non-Free software, I get through
flatpak.

Configuration containing sensitive information is in a separate
private dotfiles repository. It includes configuration for:

** Git LFS Required

This repository uses [[https://git-lfs.com][Git Large File Storage (LFS)]] to manage large
binaries (e.g., =deno=, =hugo=, AppImages, etc.).

To properly check out these files:

1. *Install Git LFS* (if you haven’t already):

   #+begin_src shell
   git lfs install
   #+end_src

2. *Clone the repo normally*—LFS hooks will auto-fetch large files:

   #+begin_src shell
   git clone https://github.com/munen/dotfiles.git
   #+end_src

** Displays (autorandr)

Two autorandr profiles in =autorandr/= (=stow autorandr=; needs the
Debian =autorandr= package):

- =docked= :: BenQ MA270S (DP-1) alone at 5120x2880, X1 panel off
- =mobile= :: X1 panel (DP-2) alone

=nvidia-drm= runs without modeset, so the kernel sends no hotplug events
and autorandr's udev rule never fires. =bin/autorandr-listen= (started
from =.xinitrc=) watches X RandR events instead and loads the matching
profile on plug and unplug. Log: =~/.cache/autorandr-listen.log=.
Design notes: =plans/2026-11-11-autorandr-benq.md=.

If a screen stays dark: =Ctrl+Alt+F2=, log in, run
=DISPLAY=:0 autorandr --load mobile=.
